# Introduction to JavaScript

## 1) What is JavaScript?  
- JavaScript is a **high-leval**, **Interpreted** programming language primarily used to make web pages **interactive**.
- It is one of the core technologies of web, alongside with **HTML** and **CSS**.

### Key features of JavaScript:
- Runs in the browser ( client )
- Supports event-driven programing
- Dynamically typed language
- Can be used on the server ( using Node.js )
- Enables creation of rich user interfaces

### Where JavaScript is Used:
- Form validation
- Interactive buttons and menus
- Animations and dynamic content
- Communicating with servers ( AJAX / fetch )
- Full-Stack web development ( with Node.js )

> JavaScript is **not the same as Java** - they are different languages.

## 2) History of JavaScript
- JavaScript was created in **1995** by **Brendan Eich** while working at **Netscape Communication**.
- Originally, it was developed in **10 days** and was called **Mocha**, later renamed to **LiveScript**, and finally to **JavaScript**.
- The name **JavaScript** was a marketing strategy - it has **no relation** to Java programming language.

### The Timeline of JavaScript History:
- **1995** - JavaScript created by Brendan Eich at Netscape.
- **1996** - Submitted ECMA for standardization.
- **1997** - First edition of **ECMAScript (ES1)** released.
- **2009** - Major update with **ES5**, including JSON support.
- **2015** - Huge upgrade with **ES6 (ECMAScript 2015)**: `let`, `const`, arrow functions, classes, modules.
- **2016-present** - Annual releases: ES7, ES8, ..., ES13 (2022).
> Now **JavaScript** is most widely used programming language in the world, powering modern web and mobile application.

## 3) JavaScript Versions
JavaScript follows a standard called **ECMAScript (ES)**, which defines the language features and syntax. New versions of ECMAScript are released regularly to improve and modernize JavaScript.

### Major JavaScript (ECMAScript) Versions:

#### ES1 to ES5 (1997–2009)
- **ES1 (1997)**: First official version
- **ES3 (1999)**: Widely adopted; added regular expressions
- **ES5 (2009)**: Major update with:
  - Strict mode (`"use strict";`)
  - `Array.forEach`, `map`, `filter`, `reduce`
  - `JSON.parse()` and `JSON.stringify()`

#### ES6 / ES2015 (2015)
A massive upgrade with modern JavaScript features:
- `let` and `const`
- Arrow functions `() => {}`
- Classes and modules
- Template literals `` `Hello ${name}` ``
- Promises
- Default parameters
- Destructuring

#### ES7 (2016) to ES13 (2022)
Smaller yearly updates:
- **ES7 (2016)**: `Array.includes()`, exponentiation `**`
- **ES8 (2017)**: `async/await`
- **ES9 (2018)**: Rest/spread for objects
- **ES10–ES13**: Optional chaining `?.`, nullish coalescing `??`, logical assignment `&&=`, `??=`, etc.

### Summary Table:

| Version      | Year  | Notable Features                             |
|--------------|-------|----------------------------------------------|
| ES5          | 2009  | JSON, strict mode, array methods             |
| ES6 (ES2015) | 2015  | `let`, `const`, classes, arrow functions     |

> Today, modern browsers support most features from ES6 and newer.
