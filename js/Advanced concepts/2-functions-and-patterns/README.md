# **2. Functions & Patterns — Overview**

### **2.1 Higher-Order Functions**
* Functions that take other functions as arguments or return functions
* Enable functional programming patterns
* Examples: `map()`, `filter()`, `reduce()`

### **2.2 Currying & Partial Application**
* **Currying**: Transform function with multiple arguments into sequence of functions
* **Partial Application**: Fix some arguments of a function, return new function
* Enables function composition and reusability

### **2.3 Function Composition**
* Combine simple functions to build complex operations
* Mathematical concept: `f(g(x))`
* Creates readable and maintainable code

### **2.4 Recursion & Tail Call Optimization**
* Functions that call themselves
* Base case and recursive case
* Tail call optimization for performance

### **2.5 Pure Functions & Immutability**
* Functions with no side effects
* Same input always produces same output
* Easier to test and reason about

### **2.6 Memoization & Caching Patterns**
* Cache function results for performance
* Trade memory for speed
* Useful for expensive computations

### **2.7 Immediately Invoked Function Expressions (IIFE)**
* Functions that execute immediately when defined
* Create private scope
* Module pattern foundation

### **2.8 Debouncing & Throttling**
* Control function execution frequency
* **Debouncing**: Delay execution until after calls stop
* **Throttling**: Limit execution to fixed intervals
