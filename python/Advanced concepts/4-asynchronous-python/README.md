# Asynchronous Python

Learn how coroutines pause cooperatively, how tasks run concurrently, and where to catch errors. These small demos use the standard `asyncio` module and require no network access.

1. [Coroutines and `await`](4.1-coroutines-and-await/README.md)
2. [Tasks and `gather`](4.2-tasks-and-gather/README.md)
3. [Async error handling](4.3-async-error-handling/README.md)

## Study guidance

**Prerequisites:** Functions, exceptions, and context managers.

**Completion checkpoint:** Own task lifetime, preserve result order deliberately, and propagate cancellation after cleanup.

Work through each lesson's additional examples and practice answer. Then apply the
ideas in the [guided projects](../../PRACTICE_PROJECTS.md) and use the
[review questions](../../REVIEW_QUESTIONS.md) to identify gaps.
